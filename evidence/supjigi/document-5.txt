# 사용자 탐색 흐름

아래는 구현에서 재구성한 과업 시나리오다. 사용자 인터뷰로 검증한 여정 지도나 실제 방문 로그는 아니다.

## 정보 구조

| 계층 | 주소 | 사용자가 할 수 있는 일 |
| --- | --- | --- |
| 진입 | `/` | 검색, 목적별 바로가기, 시작 공략, 직업별 빌드 확인 |
| 분류 | `/activities/`, `/guides/`, `/classes/`, `/skills/`, `/pets/`, `/partners/` | 분류 안에서 목록 검색·유형·직업 필터 |
| 목적형 탐색 | `/builds/`, `/skill-tiers/`, `/synergies/`, `/bosses/` | 빌드 비교, 직업별 해외 평가, 관련 근거와 전투 정보 확인 |
| 문서 | `/wiki/{category}/{slug}/` | 설명·목차·관련 문단·출처 확인, 공유 |
| 통합 검색 | `/search/?q=검색어` | 이름·관련어·질문으로 문서와 기능 탐색 |
| 적용·계산 | `/builder/`, `/growth/`, `/stats/` | 조합 편집·공유, 성장 계산, 사진 기반 능력치 점검 |
| 신뢰·운영 | `/about/`, `/updates/`, `/feedback/` | 적용 한계·변경 내용 확인, 의견 작성 |

`/classes/`는 문서형 직업 목록, `/builds/`는 빌드 탐색 진입으로 함께 존재한다. PC 왼쪽 ‘직업과 빌드’는 `/builds/`, 홈 ‘직업·빌드’는 `/classes/`로 연결된다. 포트폴리오 IA에는 실제 경로를 구분해 그리고, 동일한 메뉴명이 다른 탐색면으로 연결되는 점은 개선 후보로 남긴다. `*-preview`라는 경로/파일명이 있어도 무조건 미배포로 판단하지 않는다. [S02, S03, S10]

## 흐름 A — 처음 방문한 이용자

카톡 또는 직접 접속 → 홈 → ‘처음 시작하기’/‘처음 시작한다면’ → 초보자 가이드 → 목차의 필요한 구역 → 직업·역할 문서 → 내 직업 빌드 → 조합 연습장.

PC 홈은 전체 목적을 보여주는 바로가기와 추천 순서를 함께 배치한다. 모바일 홈은 검색 → 4개 도감 → 짧은 조합 진입 → 미검증 안내 → 시작 공략 → 직업별 빌드 → 전투 정보 → 업데이트 순으로 재구성한다. 좁은 화면에서 큰 소개 카드보다 바로 실행할 과업을 먼저 보게 하려는 설계로 해석할 수 있다. [S02, S04]

## 흐름 B — 궁금한 내용부터 검색

홈 검색 → “기사 추천 스킬” → 기사 티어표/빌드 결과 → 직업별 티어표 → 스킬 선택 → 상세창에서 효과·해외 평가 확인 → 닫아 목록으로 복귀 또는 ‘전체 설명 보기’/‘내 조합에 넣어보기’.

2026-11-15 운영에서 해당 검색의 9개 결과와 기사 티어표·빌드 연결, 방패고리 상세창을 직접 확인했다. 검색은 새 답변을 생성하는 AI 상담이 아니라 기존 페이지를 정해진 관련어·의도 규칙으로 연결한다. “시즌 바뀌면 다 사라져?”는 기존 초보자 가이드의 시즌 구역으로 연결하도록 구현돼 있다. [S05, S06, S12]

실패/대기 경로도 있다. 검색 자료 로딩 중 안내 → 실패 시 다시 불러오기, 결과 없음 → 다른 표현 제안/전체 문서 보기. 도감은 검색·필터 초기화로 복귀한다. 검색 결과는 24개씩 더 볼 수 있다.

주의: 검색어는 URL에 반영되지만 검색 범위 필터는 현재 컴포넌트 상태다. 빈 결과의 ‘전체 문서 보기’는 query 상태만 초기화하고 URL q를 같이 지우는 코드는 없다. 이 경우 새로고침 시 이전 검색어가 복원될 수 있어 개선 후보로 기록한다. 실제 재현 검사는 이번에 하지 않았다.

## 흐름 C — 읽다가 용어 확인

빌드/공략 → 스킬 이름·아이콘 → 같은 화면의 스킬 상세창 → 효과·해외 평가·확보된 범위도 → 닫기 → 읽던 문서.

스킬 전체 설명 페이지와 고유 주소는 유지한다. 긴 부가 설명은 접어서 필요할 때 열게 한다. 자료가 없는 범위 그림은 만들지 않고 없다는 안내를 한다. 데이터 요청 실패 시 전체 설명 페이지로 우회한다. 상세창 종료 후 원래 초점으로 복귀하는 코드가 있다. [S07, S08, S12]

## 흐름 D — 모바일 조합 만들기와 공유

하단 ‘조합’ → 스킬/비법 슬롯 선택 → 선택창에서 이름·효과 검색/직업 필터 → 항목 선택 → 조합판 확인 → 판타몬·파트너 선택 → 출처 문단 검토 → 새 조합 이름으로 저장 또는 공유 링크/이미지 저장.

모바일 ‘내 조합 / 추천 빌드’ 전환으로 한 번에 볼 대상을 나눈다. PC에는 드래그앤드롭과 추가 버튼이 함께 존재한다. 저장은 현재 브라우저에 한정되므로 다른 기기로 전달할 때는 링크가 필요하다. 받은 조합은 저장본과 다른 슬롯을 확인하고 필요한 항목만 가져오도록 구현돼 있다. [S09]

## 지속 탐색과 복귀

- PC: 상단의 큰 과업 메뉴 + 왼쪽 문서 분류. `aria-current`로 현재 위치 표시.
- 모바일: 검색만 남긴 상단 헤더, 문서 페이지의 가로 분류 메뉴, 홈·검색·조합·피드백·업데이트 5개 하단 메뉴. 홈에서는 중복 가로 분류를 숨긴다.
- 상세: breadcrumb → 문서 목차 → 관련 정보 → 출처 → 목록으로/맨 위로.
- 도감: 같은 탭의 sessionStorage로 검색어·유형·직업·더 보기 개수를 복원한다. 모든 탐색 상태나 스크롤을 직접 저장하는 구현은 아니다. 스크롤 복귀는 브라우저 동작과 구분한다.
